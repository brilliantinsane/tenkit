Tenkit generates standalone Expo projects around an explicit **Setup Type** and exactly 32 supported **Generated App Options** combinations.

Tenkit is short for Tenant Kit: a focused kit for generating multi-tenant Expo projects without hiding the relationship between App Variants and Runtime Tenants.

Use the Configurator to explore a selection, then copy a reproducible Public CLI command:

```bash
pnpm create tenkit@latest
```

The generated project keeps its Expo app at the root. A selected Backend may add an `apps/server` workspace, and selected SQL storage may add a `packages/db` workspace. The generated project contains one resolved stack, not a runtime switch between technologies.

## What Tenkit owns

Tenkit owns the generated project shape, Setup Type behavior, App Variant native identity, Runtime Tenant Access bootstrap, and Build Preparation guidance. Your generated project owns its product code, provider accounts, credentials, deployment, and production data.

The Public Web App explains and serializes Choices. The Public CLI owns project creation policy. The generated app's local CLI owns operations inside that generated project.
